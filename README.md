## About

I build across the stack — Ruby and Node on the server, React on the web,
and React Native on mobile, with Go when the workload calls for it. I care
about clean data flows, fast iteration, and shipping things that hold up
in production.

Currently building **Rukmae** — a multi-tenant restaurant management
system used by multi-outlet chains to run counter orders, KOTs, inventory,
staff payments, and bus-fleet arrivals in one place. A React web dashboard,
a React Native counter app, and a Spring Boot microservices backend behind
an API gateway.

## What I work on

- **Full-stack product work** — designing the schema, shipping the API,
  wiring the UI, all the way to release.
- **Mobile** — React Native + Expo, offline-first flows (queued sync,
  ledger fallbacks), English/Marathi i18n.
- **Backend** — REST APIs, PostgreSQL, JWT auth with role-based
  permissions, migration discipline.
- **Web** — React + TypeScript, TanStack Query, sensible component
  composition.
